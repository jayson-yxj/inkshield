启动与环境
完整解压压缩包，保持 Inkshield 文件夹及 _internal 全部文件在一起，再双击 Inkshield.exe。无需安装 Python；这是文件夹便携版，请勿只复制 EXE。首次加载模型可能需要等待。
目标为 Windows 10 / 11 Intel、AMD 64 位电脑。建议至少 8GB 内存；程序解压约 4.5GB，建议为压缩包、解压目录预留至少 10GB，另留足视频、遮罩缓存与导出的空间。未承诺低内存设备性能；仅当前验收电脑完成实测，其他配置需试运行确认。
桌面窗口使用系统 WebView2 和 .NET Framework；不可用时尝试默认浏览器及本地服务小窗口，使用期间请保留该窗口，退出时关闭它。本包不自动联网安装系统组件。
CUDA 运行库随包提供；SAM2.1 启动预热优先使用可用 NVIDIA GPU，GPU 无法启用时回退 CPU并显示原因。GPU 需要兼容的 NVIDIA 显卡和驱动，不需要单独安装 CUDA Toolkit。包内 SAM_PACKAGING.md 的能力接口兼容默认CPU描述需更正：底层引擎默认字段为CPU，但服务接口会覆盖为优先设备或预热成功设备，界面采用预热结果；该文档中的2026-11-09数据仅为历史构建记录。人脸/车牌检测使用 CPU。无可用 GPU 时可使用 CPU，速度取决于电脑与素材。

工作区与教程
顶部教程可查看操作演示。导入视频只读取素材信息，不自动分析。使用时间线定位、分割和缩放；选中视频片段后编辑。当前图层模式通过顶部模式按钮切换，效果选择状态下先按 Esc 取消选择。
每个视频片段可使用多个独立图层，分别设置自动检测或自定义区域，添加、选择和调整效果片段；选中效果时，共用工具栏修改该效果，取消选择后编辑当前图层。自动检测支持人脸/车牌、人物选择及样式调整。分析后的样式与强度变化无需重跑模型；检测阈值变化用于下次分析。
自定义区域：先等待 SAM2.1 预热，暂停到目标帧，添加包含点或排除点，立即计算该帧预览；同帧补点复用特征。每个标注帧至少需要一个包含点。可从中间帧标注并向前、向后传播。点击传播后检查整个片段，多个目标可分到不同图层处理。
自定义传播每个片段最多150帧，原始尺寸最高1280×720；长素材可先点选单帧预览，传播前须手动分割为支持长度。高级选项可指定下次 SAM 任务的 CPU/GPU；手动指定设备失败会报告错误，不会静默改设备。更改设备不会重算已有结果。
批量传播串行处理同一视频片段中有提示点且尚未就绪的自定义层，跳过空层、已就绪层和自动层。某项失败时保留已完成结果并停止后续任务；修正后重试只处理剩余待完成层。点选预览为原视频上的半透明区域；传播完成后的合成预览和导出才应用遮罩效果。
左右面板可收起和展开。自定义模式下可按住空格并用鼠标左键拖动，或用鼠标中键拖动来平移画面；使用复位按钮恢复视图。
连续保护播放先生成合成视频，再由浏览器播放；首次生成有等待时间，逐帧定位使用合成帧。选中片段播放该段，取消选中可连续播放；未保护或保护不完整时预览仍可播放，未分析处可能显示原视频，请逐段检查保护覆盖；启用且有效的图层仍有待完成分析时，导出会严格拒绝。切点、效果区间或图层变化可能使已有分析失效，请按界面提示重新分析。
静音开关同时作用于预览和下一次导出，默认静音。关闭静音时保留素材原音轨（转为AAC）；素材无声音则仍无声。导出选中片段，完成后点击下载保存；暂不自动合并全部视频片段。

数据与退出
数据目录为 %LOCALAPPDATA%\Inkshield；日志为该目录内 inkshield.log，上传视频、分析遮罩、播放缓存和导出位于 runtime 子目录。程序仅监听本机回环地址，不自动上传素材，内置模型可离线处理。
缓存按磁盘空间检查，没有固定5任务上限；空间不足时拒绝新任务，不自动删除已有结果。保存所需输出并完全退出程序后，可自行清理旧缓存；清理会失去相应本地结果。程序重启不恢复未保存编辑会话，关闭时会停止进行中的任务。

限制与检查
素材上限512MiB、18000帧；单帧受像素总量限制。自定义传播另有上文150帧和1280×720限制。部分编码可能无法在浏览器解码，可先转换为常见H.264 MP4。变帧率素材不保证精确音画对齐。
自动检测可能漏掉小目标、侧脸或遮挡；SAM点选可能选多、跟丢。请检查整个片段与最终输出。轻度模糊、羽化不保证彻底不可识别。
当前版本未数字签名，Windows可能显示未知发布者。启动失败请查看日志、磁盘空间及目录写入权限；若系统缺少VC++运行时导致DLL错误，可从微软官方安装x64 Visual C++ 2015-2022 Redistributable。
