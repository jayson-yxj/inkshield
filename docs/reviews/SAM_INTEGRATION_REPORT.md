# 隐映 SAM2.1 集成验收记录

当前状态：源码集成与Windows构建完成；同一EXE的CPU、CUDA接口和完整原生交互验收通过，旧人脸/车牌/音频及正常桌面启动关闭验收通过；最终压缩包已生成，ZIP逐文件CRC与内嵌EXE SHA核验通过。以下证据分别记录，不能互相替代。

## 功能

正式编辑器提供“自动检测”和“自定义区域”两种模式。自定义模式按片段保留包含/排除点及下次计算设备；每个有点的帧必须包含正点。点击自动触发当前帧分割，特征缓存按视频、区间、设备、帧隔离，最多缓存两帧。确认后由用户启动完整片段传播。

SAM 默认 CPU，高级选项可选择可用的 NVIDIA CUDA。请求显式 GPU 但不可用时返回错误，不静默替换为 CPU。切换设备不改变既有缓存结果；传播结果保留实际设备元数据。

分析生成不可变逐帧掩码。预览、六种样式导出共用后端合成规则，外扩6像素。请求自定义保护但掩码缺失或任意帧为空时阻止导出。自定义播放按需读取合成 JPEG，保留上一帧等待，速度依赖本机。点选阶段原视频叠加半透明青色区域表示模型选择，不等同于完成打码。

当前范围：一个目标、最多150帧、原始尺寸不超过1280×720，超限明确拒绝。SAM3未集成。持久化SAM目录最多5个，不自动删除现有结果；失败任务清理本次未发布目录。重启不恢复内存编辑会话。

## 真实 CPU 接口与导出

证据：runtime/sam-api-real-20261109-verify2/evidence.json。

Windows 1280×720、25fps、5帧带音频素材；分析原始区间[1,4)，包含片段本地帧1的提示点。专用CPU运行环境、4线程。首次点击墙钟11.126秒（推理接口11.008秒），同点重复0.281秒（接口0.165秒），补点0.266秒（接口0.155秒）。同帧重复/补点命中特征缓存，重复输出PNG哈希一致。三帧传播状态墙钟20.106秒，SAM阶段19.913秒。

六种样式的预览及导出均可解码；空目标选择保持原始内容；黑色输出分别验证保留音轨和静音；逐帧预览与有损编码输出最大MAE3.235。分析缓存内容哈希及mtime保持不变。非法非有限坐标、越界点、负点独立帧、非法区间及不可用CUDA请求均明确拒绝。

该CPU环境使用研究环境已有的CPU Torch，不能据此推断正式CUDA打包环境的CPU性能。模型非空、输出可解码及缓存命中不证明语义选区正确或隐私覆盖充分。
