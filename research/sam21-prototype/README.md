# 隐映 SAM 2.1 点选目标试验

这是独立的本地研究原型，正式时间线编辑版保持不变。SAM 3 尚未接入，等待你下载好权重后再试。

## 本机启动

双击“启动点选试验.cmd”，或在本目录右键运行 start_trial.ps1，也可在 PowerShell 执行：

```powershell
& .\.venv\Scripts\python.exe app.py
```

程序仅监听本机随机端口并打开浏览器。关闭服务控制台即可停止；浏览器关闭不代表服务已停止。也可以由提供的本次运行地址进入。不要同时启动多个实例。

## 使用

1. 导入短视频。本次限制最高1280×720、256MB、最多150帧。长输入仅导入前150帧，界面明确显示截断；不表示处理了完整原片。
2. 在目标内部点击正点，在误选区域点击负点；可移动到其他帧补点。每个有提示的帧都必须有至少一个正点，仅有负点不能单独修正。仅记录提示点，不承诺即时响应分割。
3. 点击“生成全片段遮罩”。官方SAM 2.1 tiny在CPU上从提示帧向前/后传播，每次补点重新计算当前片段。
4. 逐帧查看青色掩码或处理后预览，误选时继续补点。空掩码帧会提示未受保护。模型对点击目标的理解可能包含整个人、衣服或背景，必须目视核对。
5. 选择马赛克、高斯模糊或黑块，调整强度与向外扩张后导出。本次导出无声音，保持导入片段帧数和帧率。掩码核心不羽化，避免边缘透明混回目标。

本次只支持一个目标；不提供自然语言选择、多目标正式时间线集成或独立EXE。依赖与权重留在本机，启动后无需下载模型。专用环境目前借用已有研究环境的CPU torch，不是可拷到其他机器直接运行的便携包。

## 数据与许可

导入原文件、解码JPEG帧、提示点、二值掩码、导出和测试结果保存在本目录runtime。停止服务不会自动删除；重启后网页会话不恢复，请重新导入。保留最多5段视频目录，每段最多5次传播和5份导出；任务前3GiB软阈值会阻止继续添加，单个进行中的任务可能超过阈值。达到限制后需停止服务、手动整理runtime，重启不会绕过目录数量限制。独立试验资料不写入正式应用缓存。

代码、权重来源、固定版本及许可证见模型准备记录。分割和遮罩通过技术测试不等于在所有画面上完成隐私保护，也不代替用户对目标范围的核对。
